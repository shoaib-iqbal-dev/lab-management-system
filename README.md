# Laboratory Management System

### Project Overview
The Laboratory Management System is a web-based application designed to automate the process of patient record-keeping and diagnostic reporting. It replaces manual, paper-based workflows with a digital interface, significantly reducing human error and improving data retrieval speeds.

### Tech Stack
- **Frontend:** HTML5, CSS3 (Bootstrap), JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Environment:** XAMPP (Apache)

### Why I Built This
Having worked in medical data operations at AIMS Hospital (managing 200-300 records daily), I noticed how manual paperwork slows down patient care. This project was developed as a solution to automate diagnostic reporting and ensure data integrity.

### Development Methodology (AI + Human Logic)
Following a modern development approach, I used **AI-Assisted Workflows** (ChatGPT/Gemini) to generate the initial database schema and CRUD (Create, Read, Update, Delete) operations. 
- **The Human Element:** I manually rebuilt the security logic, added session-based authentication for staff logins, and performed manual debugging of the SQL joins to ensure patient data is handled accurately and securely.

### Key Features
- **Patient Registration:** Seamlessly add and manage patient profiles.
- **Diagnostic Reporting:** Automated generation of lab results and reports.
- **Record Management:** Searchable database for historical patient data.
- **Security:** Secure login protocols for laboratory technicians and administrators.

### How to Run
1. Clone the repository to your local machine.
2. Move the project folder to the `htdocs` directory of your XAMPP installation.
3. Import the provided `.sql` file into your MySQL database (phpMyAdmin).
4. Access the application via `localhost/Lab-Management-System`.
